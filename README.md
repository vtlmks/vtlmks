# Lord Orangutan, Third Earl of Not My Problem

*Distinguished Fellow, Royal Society of Unsolicited Pull Requests.*

C & Assembly programmer. M680x0, x86/x86-64. Specialising in persuading processors to do considerably more work than they initially appeared willing to undertake.

### Areas of Particular Interest

- **[ffpng](https://github.com/vtlmks/ffpng)** — A high-performance PNG decoder written from scratch in C.
- **[mindchess](https://github.com/vtlmks/mindchess)** — A high-performance chess move generator. Billions of positions examined per second. His Lordship remains unable to play chess at anything approaching this speed.
- **[ipv6-avx512](https://github.com/vtlmks/ipv6-avx512)** — A high-performance IPv6 parser using AVX-512.
- **[mkgui](https://github.com/vtlmks/mkgui)** — A lightweight GUI toolkit for Linux and Windows, written in C with minimal dependencies.
- **[mkcomp](https://github.com/vtlmks/mkcomp)** — A lightweight X11 compositor featuring shadows, rounded corners, and other modern conveniences.

### Research Interests

Instruction scheduling, SIMD, cache behaviour, memory latency, branch prediction, and the increasingly unreasonable expectation that fewer instructions should result in less execution time.

His Lordship believes performance claims should be supported by reproducible measurements.

The compiler has occasionally expressed a different opinion.
